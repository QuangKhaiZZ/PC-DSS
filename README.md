# PC-DSS

Hệ hỗ trợ ra quyết định lựa chọn cấu hình máy tính cá nhân dựa trên nhu cầu, ngân sách, hiệu năng và khả năng tương thích linh kiện.

## Công nghệ

- Backend: ASP.NET Core Web API
- Database: MySQL
- ORM: Entity Framework Core
- Frontend: React 18, Vite 6

## Trạng thái

- Đã hoàn thành nền tảng backend và API CRUD Category.
- Đã tích hợp giao diện React và CRUD Category với Backend API.
- Database linh kiện và thuật toán DSS chưa hoàn thành.

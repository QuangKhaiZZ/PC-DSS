# Tài liệu PC-DSS

Hệ thống lựa chọn bộ PC có sẵn theo ngân sách và nhu cầu Gaming hoặc Rendering. Frontend đã tích hợp API; danh mục hiện có 36 PC. Dữ liệu triển khai được lưu bằng CSV và JSON.

- [Yêu cầu hệ thống](requirements.md)
- [Kiểm tra mô hình](model-check.md): kết quả và giới hạn của lần kiểm tra đã lưu.
- [Postman](PC-DSS.postman_collection.json): bộ request tham khảo.
- [Sơ đồ use case](../output/report-images/PC-DSS-Use-Case-da-sua.png)
- [Backend](../backend/README.md) và [kiểm thử API](../backend/tests/README.md)
- [Dữ liệu](../data/README.md), [mô hình](../models/README.md) và [notebook](../notebooks/README.md)

Các tài liệu đánh giá mô hình cần được đọc kèm phạm vi dữ liệu và thời điểm kiểm tra; việc chạy đúng phần mềm không thay thế xác minh nguồn benchmark hoặc đánh giá khả năng dự đoán trên dữ liệu mới.

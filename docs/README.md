# Tài liệu PC-DSS

Phạm vi hiện tại: chọn bộ PC có sẵn theo ngân sách và Gaming/Rendering; lưu CSV, không kiểm tra tương thích.

- [Yêu cầu hệ thống](requirements.md): chức năng, giới hạn và tiêu chí nghiệm thu.
- [Thiết kế DSS](dss-design.md): dữ liệu, model, lọc và xếp hạng.
- [Tích hợp frontend](frontend-integration.md): luồng giao diện và API.
- [Thu thập dữ liệu](data-collection-template.md): bổ sung PC và reference.
- [Kiểm tra mô hình](model-check.md): kết quả và giới hạn đánh giá.
- [Postman](PC-DSS.postman_collection.json): request mẫu.
- [Chạy backend](../backend/README.md), [kiểm thử API](../backend/tests/README.md).
- [Dữ liệu](../data/README.md), [model](../models/README.md), [notebook](../notebooks/README.md).

Backend đã hoạt động; frontend chưa nối API mới. Danh mục có 12 PC kiểm thử, dự kiến mở rộng 40–50 PC. Tài liệu SQL trong database/ và báo cáo giữa kỳ là hồ sơ giai đoạn trước, không dùng làm yêu cầu triển khai hiện tại.
